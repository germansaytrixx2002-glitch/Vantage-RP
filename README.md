# Vantage Economy Bot

Diese Struktur enthält ein separates Wirtschaftssystem für einen Discord-Bot.

## Ordnerstruktur

- `index.js` – Startet den Bot und verbindet ihn mit Discord
- `economy.js` – Enthält alle Wirtschaftsbefehle und Logik
- `data/economy.json` – Speichert alle Nutzerdaten
- `.env` – Enthält deinen Bot-Token
- `.env.example` – Beispiel für die Umgebungsvariablen
- `package.json` – Enthält die Projektmetadaten und Abhängigkeiten

## Starten

1. `.env` mit deinem echten Bot-Token füllen
2. `npm install`
3. `npm start`

## Beispielbefehle

- `!help`
- `!balance`
- `!daily`
- `!work`
- `!shop`
- `!buy booster`
- `!inventory`
- `!leaderboard`
- `!rob @nutzer`

## Hinweis

Der Bot läuft nur lokal, solange der Computer eingeschaltet ist.
